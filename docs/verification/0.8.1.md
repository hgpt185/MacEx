# 0.8.1 — library discovery, sidebar and appearance verification

Date: 2026-10-27. This update addresses incomplete real-file discovery, sidebar alignment and click areas, and appearance controls while retaining the single-window workflow.

## Implemented behavior

- Routes, saved searches, locations and Add Library Folder share aligned symbol/title/count columns and full-width padded button labels. Blank areas, symbols and padding activate the same action; the selected route has one rounded highlight.
- System, Light and Dark apply to the native window and SwiftUI content and persist across launches. System follows macOS. Playful colors are independent of appearance.
- Ordinary launches reconcile metadata from `/Applications`, `~/Applications`, `/System/Applications`, and Desktop, Documents, Downloads, Pictures, Music and Movies under the user's home folder. Up to eight saved custom roots remain supported and preserved. App bundles appear as catalog entries without scanning their descendants.
- Default-location opt-outs persist. Adding an excluded location again re-enables it. Missing optional folders are skipped; denied/unavailable folders and scan limits have coverage warnings. One denied subtree does not suppress later accessible roots. Metadata discovery retains its global 20,000-item, 100,000-examined-entry and depth-32 bounds; online-only content is not hydrated.
- Categories, exact-duplicate comparisons and Similar Photos use the same library catalog. Duplicate candidates must still be unchanged, local, regular files and pass existing identity/hash/byte checks. Similarity remains approximate and requires review.
- Optional rules remain off by default and use only explicit custom folders. Automatic discovery does not expand their scope. Enabled rules check every 30 minutes while the app is open; library refresh never runs them. Standard locations require explicit addition as custom rule folders.
- Explicit `--state-directory` profiles do not automatically discover real personal/application roots and display **Isolated library**. OCR remains a separate opt-in; application roots/bundles are excluded from recognition.

Native clicks in the trailing blank area of Recents and the leading blank area of Images opened those routes with 227 and 70 entries respectively; the sidebar columns appeared aligned. The top-bar appearance control switched the full app from System (effective Dark) to Light and Dark.
