> **For agentic workers:** Use superpowers:executing-plans or superpowers:subagent-driven-development for assigned tasks. Parent owns integration and the SwiftPM build lane.

**Goal:** Replace imitation folder cards with recognizable folders and repair related presentation defects.
**Architecture:** Pure SwiftUI folder artwork with a generic preview slot; existing library buttons keep their navigation. Actual browser folders use native AppKit imagery.
**Tech Stack:** SwiftUI, AppKit, Swift 6, macOS 14+.
**Spec:** `docs/superpowers/specs/2026-10-29-folder-ui-design.md`.

## Global Constraints
- Keep navigation and file workflows in the existing window; never launch Finder.
- Preserve the user's README/video work and current source artwork.
- No personal file moves, deletion, automation, new dependencies or demo catalog data.
- Only parent runs SwiftPM/full builds; native icon worker owns disjoint files.

- Narrow cards and long metadata do not overflow or clip.

- Both appearance modes retain folder depth and legible text.
- Entire category tile activates its route with keyboard/accessibility support.
